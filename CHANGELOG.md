# Changelog

All notable changes to Mindora will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.1] — 2026-07-08

### Branding
- **Renamed to Mindora** — new product name, logo, color palette (Aurora violet / cyan), and favicon.
- CLI command renamed from `pi-web` to `mindora` (no behavioral change).
- npm package renamed from `@agegr/pi-web` to `mindora`.

### Documentation
- New English and Chinese README rewritten around the Mindora brand.
- New [CHANGELOG.md](./CHANGELOG.md), [CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md), and [CONTRIBUTING.md](./CONTRIBUTING.md).
- Logo SVG added at `docs/logo.svg`.

### Internationalization
- **Zh-CN, En-US, Ja-JP** UI strings for chat input placeholders, control tooltips, top-bar buttons, branch-navigator labels, export/save flows, and sidebar actions.

### Notes
- This is the first Mindora release. The codebase, architecture, and pi-coding-agent integration are inherited from [`@agegr/pi-web` v0.7.8](https://github.com/agegr/pi-web) (MIT, © agegr). Mindora adds the brand layer, ongoing product work, and a maintained rebrand on top.
